# Credlock Intern Portal

A modern internal web application for managing SIWES/intern onboarding, learning plans, attendance, tasks, progress, assessments, and reporting.

## Development

This project is designed to be developed and maintained with **Visual Studio Community** using **ASP.NET Core Razor Pages / C#**.

## Initial scope

- Secure authentication and role-based access
- Intern profiles and onboarding
- Department and supervisor management
- 12-week learning plans and course tracks
- Daily attendance and activity logging
- Tasks, assignments, and progress tracking
- Assessments and supervisor evaluations
- Notifications and announcements
- HR/admin dashboard and reports
- Responsive desktop/mobile-friendly interface
